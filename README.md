# Bike Sales Analysis & Customer Demographics Dashboard | Excel

## Project Overview

This project focuses on analyzing bike sales data to understand customer purchasing patterns, demographic characteristics, and commuting behaviour using Microsoft Excel.

The objective was to transform raw sales data into meaningful insights through data cleaning, PivotTable analysis, and dashboard visualization.

## Tools & Skills Used

- Microsoft Excel
- Data Cleaning and Preparation
- PivotTables
- Data Aggregation
- Excel Charts
- Dashboard Development
- Customer Demographic Analysis

## Project Workflow

### 1. Raw Data
Preserved the original dataset separately to maintain data integrity and ensure the source data remained unchanged.

### 2. Data Cleaning
Created a separate working sheet by copying the raw dataset and preparing the data for analysis through cleaning and formatting.

### 3. PivotTable Analysis

Performed analysis across the following areas:

- Customer commute patterns
- Average income per purchase by gender
- Customer age bracket analysis

### 4. Dashboard Development

Created an Excel dashboard to present the key analytical findings through charts and visual summaries.

## Key Analytical Areas

- Customer purchasing behaviour
- Gender-based income analysis
- Customer age segmentation
- Commuting patterns

## Project Files

- Excel workbook containing the raw data, cleaned working sheet, PivotTables, and final dashboard.

## Limitations

Interactive PivotTable features such as slicers and additional PivotTable analysis controls were not available in the Excel version used for this project.

## Conclusion

This project provided practical experience in data preparation, exploratory analysis, PivotTables, and Excel dashboard development.

The analysis demonstrates how raw sales data can be structured and transformed into an organized visual report to support business understanding and decision-making.
